# 勤怠管理・給与計算システム (TimeCard & Payroll System)
## 📌 開発の背景・きっかけ
  前職の派遣社員時代に、残業時間の管理が曖昧だったことで給与の未払いが発生するという苦い経験をしました。
  「 労働者が正当に働いた分の対価を、1分単位で正確に、透明性を持って計算できるシステムを作りたい」という強い思いから、このシステムを開発しました。

## 🚀 概要
Javaで開発した、従業員の出退勤管理および給与の自動計算システムです。
労働時間の適正な記録と、それに基づいた正確な残業代の自動算出を行い、給与の「未払い」や「計算ミス」を防ぎます。
理想としては、毎日使うものなのでPCが苦手な人でも使ってもらえるように簡略化したい。

## ✨ 主な機能

### 1. 従業員管理機能
* 従業員の新規登録（氏名）
* 契約時給の割り当て
* ログイン権限管理（一般社員 / 管理者）※実装予定

### 2. 勤怠登録・管理機能
* 出勤・退勤・休憩時間の記録（日付＋時刻の保持）

### 3. 給与・残業代の自動計算機能（★こだわりのポイント）
* 1日8時間を超える「法定外残業時間」の自動切り出し（割増率 1.25倍）
* 給与計算の履歴保持（時給改定に対応）
