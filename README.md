# 勤怠管理・給与計算システム

Javaで開発した、個人向けの勤怠管理・給与計算システムです。

出勤・退勤時刻から実働時間、残業時間、給与を自動計算し、勤務記録をCSVファイルへ保存します。

## 📌 開発の背景

前職で派遣社員として働いていた際、残業時間の管理が曖昧だったことから、給与の未払いを経験しました。

この経験をきっかけに、働いた時間と給与を1分単位で記録し、会社側の勤怠データとの違いを確認しやすくすることを目的として開発しています。

毎日使用することを想定し、PC操作が苦手な方でも迷いにくい、シンプルなシステムを目指しています。

## ✨ 主な機能

### 初期設定

初回起動時に、次の情報を登録します。

- 氏名
- 時給
- 1日の契約労働時間
- 標準休憩時間

登録した情報は `config.csv` に保存され、次回起動時に自動で読み込まれます。

### 勤怠登録

- 勤務日の入力
- 出勤時刻の入力
- 退勤時刻の入力
- 実働時間の自動計算
- 残業時間の自動計算

### 給与計算

- 実働時間に応じた給与の計算
- 契約労働時間を超えた残業時間の計算
- 残業手当の計算
- 保存済みデータの集計表示

### 勤務記録の保存

計算した勤務記録を `worklog.csv` に保存します。

同じ日付・同じ氏名のデータが存在する場合は、新しい入力内容で上書きします。 入力を間違えた場合も、同じ日付で再入力することで修正できます。

## 🔄 システムの流れ

1. 初回起動時に基本情報を登録する
2. 勤務日を入力する
3. 出勤時刻と退勤時刻を入力する
4. 実働時間と残業時間を計算する
5. 給与と残業手当を計算する
6. 計算結果をCSVファイルへ保存する
7. 保存済みの勤務記録を集計する

## 🚀 実行方法

### 1. リポジトリをクローンする

```bash
git clone https://github.com/YSK-do/TimeCard-Payroll-System.git
cd TimeCard-Payroll-System
```

### 2. コンパイルする

```bash
javac src/JobManager.java
```

### 3. 実行する

```bash
java -cp src JobManager
```

## 📝 入力例

```text
日付を入力してください：2026-07-19
出勤時間を入力してください：9:30
退勤時間を入力してください：18:30
```

時刻は `時:分` の形式で入力します。

全角数字や全角のコロンを入力した場合も、半角へ変換して処理します。

## 📁 保存ファイル

プログラムを実行したディレクトリに、次のCSVファイルが作成されます。

| ファイル | 保存内容 |
| --- | --- |
| `config.csv` | 氏名、時給、契約労働時間、標準休憩時間 |
| `worklog.csv` | 日付、氏名、実働時間、残業時間、給与、残業手当 |

## 💡 設計上の工夫

### 時間を「分」に統一

時間を「時」と「分」に分けたまま計算せず、すべて合計分へ変換しています。

これにより、実働時間や残業時間の計算を分かりやすくしています。

### クラスごとに役割を分離

| クラス | 役割 |
| --- | --- |
| `Mytime` | 時刻の変換と時間差の計算 |
| `Config` | 氏名や時給などの設定情報を管理 |
| `WorkRecord` | 勤務記録とCSVデータを管理 |
| `JobManager` | 入力、計算、保存、集計を実行 |

### 勤務記録の上書き

日付と氏名が一致するデータは、重複して追加せず、新しい入力内容へ置き換えます。
